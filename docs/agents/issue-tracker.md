# Issue Tracker Configuration

- **Tracker Type**: Local Markdown Tracker
- **Issues Directory**: `.scratch/issues/`
- **Triage Workflow**:
  - `needs-triage`: Isu/tugas baru yang belum diproses
  - `needs-info`: Memerlukan konfirmasi atau klarifikasi pengguna
  - `ready-for-agent`: Siap dieksekusi secara otomatis oleh asisten coding
  - `ready-for-human`: Memerlukan tindakan manual pengguna
  - `wontfix`: Tidak akan dikerjakan
